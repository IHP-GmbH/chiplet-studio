# Black-box chiplet demo

Visual-verification fixture for the **black-box render path**: a chiplet from a
commercial / closed PDK node whose GDS carries only metal pads and pad names,
with **no** layer-properties (`.lyp`) file. The studio falls back to
default-layer rendering.

## Files

- `acme_phy.spec.json`: pad spec, 8 named pads on a 2000x1500 um die.
- `acme_phy.gds`: synthesized GDS, pads on 205/0, names on 205/25, outline on
  206/0. Generated by `gds_to_kicad/blackbox_chiplet.py`.
- `acme_phy.boundaries.json`: die-outline boundary manifest (ADK assembly
  metadata; inert for the viewer, consumed downstream by assembly DRC).
- `blackbox_demo.chiplet`: assembly with a `closed_pdk` technology that omits
  `layer_properties`, so its component renders via the black-box path.

## Run

    ./scripts/run-blackbox-demo.sh

Docker + X11 (needs the `chiplet-studio-build` image and a built binary). The
`build/chiplet-studio` binary is Docker-built and will **not** run directly on
the host; always launch through the script.

## What to look for

2D drill-down (drill into the die):

- [ ] Pad rectangles drawn and auto-colored (KLayout default layer colors).
- [ ] Pad **names** render as text: VDD, VSS, CLK, RST_N, SDA, SCL, TX, RX.
- [ ] Layer-control panel lists the auto-created layers (205/0, 205/25, 206/0).
- [ ] Drill-down context label reads `Component: acme_phy (closed_pdk)`. The
      `Assembly (black-box / default layers)` label is the assembly-mode label,
      shown before you drill in.

3D view:

- [ ] The pad layer extrudes as thin slabs (stackup augmented for the foreign layer).
- [ ] No crash when toggling layers or rotating.

3D pad-name **text** is intentionally not rendered yet; names show in 2D only.

## Regenerate the GDS

    cd ../../../gds_to_kicad
    venv/bin/python blackbox_chiplet.py \
      ../chiplet-studio/examples/blackbox/acme_phy.spec.json \
      -o ../chiplet-studio/examples/blackbox/acme_phy.gds
